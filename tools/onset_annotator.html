📖 用法 & 把 gold MIDI 轉成 ghost 參考
1) 載入 outputs/songid/vocals.wav。
2) （可選）載入參考：data/alignment_gold/songid.gold.tsv 會以灰色 ghost 顯示現有句首/句尾，你就能對照「我聽到的」與「現行 gold」。
3) 把要標的句子貼進「貼歌詞」→「從文字建立行」。在每行：循環試聽該段（行列的 ▶），把播放頭移到你聽到的句首，按 Q（或行內 set start）；句尾按 W。
4) 要更細（每個 mora 的 onset / 音尾 offset）就用 E/R 或自訂標籤。
5) 匯出 TSV/JSON。

把 note gold MIDI 轉成 ghost（在 repo 根、karaoke-jp venv）： 
~/venvs/karaoke-jp/bin/python - <<'PY'
import mido,json
m=mido.MidiFile("gold/songid/songid_ref_full_wide_clean_humanfix.mid");ppq=m.ticks_per_beat
ev=[]; # nominal 120bpm -> sec = tick*0.5/ppq
for tr in m.tracks:
    t=0;act={}
    for x in tr:
        t+=x.time
        if x.type=='note_on' and x.velocity>0: act.setdefault(x.note,[]).append(t)
        elif x.type=='note_off' or (x.type=='note_on' and x.velocity==0):
            if act.get(x.note): a=act[x.note].pop(0); ev.append({"onset":a*0.5/ppq,"offset":t*0.5/ppq,"pitch":x.note})
json.dump(sorted(ev,key=lambda e:e["onset"]),open("tmp/songid_gold_notes.json","w"))
print("wrote tmp/songid_gold_notes.json",len(ev))
PY
然後用「載入參考」選 tmp/songid_gold_notes.json，note onset/offset 會變 ghost 線。
